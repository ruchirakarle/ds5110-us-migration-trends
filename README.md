## Project Goals
- Compare U.S. domestic migration patterns before (2017–2020) and after (2020–2023) the COVID-19 pandemic
- Identify the 10 states with the highest inflows and outflows
- Examine migration to and from major cities such as Boston, New York City, and Los Angeles
- Compare the incomes of households moving into and out of these areas
- Forecast what migration would have looked like without the pandemic, and compare with actual data

## Data
IRS Statistics of Income (SOI) Migration Data:
https://www.irs.gov/statistics/soi-tax-stats-migration-data

Data files are **not** stored in this repository because of their size. Run the download scripts in `R/` to get the data.
